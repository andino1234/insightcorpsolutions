# Insight Solutions — Sitio corporativo

Sitio web corporativo bilingüe (inglés / español) para **Insight Solutions**, firma de consultoría estratégica con presencia en Honduras, El Salvador, Guatemala y Panamá.

## Características

- Diseño *responsive* con navegación móvil.
- Selector de idioma inglés / español sin recargar la página.
- Animaciones de aparición al hacer scroll (*reveal on scroll*) con `IntersectionObserver`.
- Secciones de servicios, metodología, oficinas y contacto.
- Sitio 100 % estático: no requiere backend ni proceso de compilación.

## Tecnologías

HTML5 · CSS3 (variables, Grid, Flexbox) · JavaScript vanilla

## Estructura

```text
index.html     Página principal
styles.css     Estilos del sitio
script.js      Menú, animaciones y cambio de idioma
assets/img/    Imágenes y logotipo
```

## Ejecución local

Abre `index.html` en el navegador o sirve la carpeta con cualquier servidor estático, por ejemplo:

```bash
npx serve .
```
